# PlaceTrack 🎯

A placement tracking web app for college campuses. Students track every company they apply to, from application to offer, while placement faculty oversee the process.

> 🚧 **Status: Work in progress.** This is my first project, and I'm adding features one by one.

---

## 📖 About

Placement season is chaotic: dozens of companies, multiple rounds, and deadlines scattered across WhatsApp groups and spreadsheets. **PlaceTrack** aims to put everything in one place.

The app is built for two types of users:

| Role | What they do |
|------|--------------|
| 🎓 **Student** | Tracks applications, rounds, packages, and upcoming dates |
| 👨‍🏫 **Admin (Placement Faculty)** | Manages and oversees the placement process |

## 🚀 Getting Started

No installation or build step is needed.

1. **Clone the repository**
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   ```
2. **Open the project folder**
   ```bash
   cd <your-repo-name>
   ```
3. **Open `login.html` or `HTML.html` in your browser**, or use the *Live Server* extension in VS Code.
